# Kanban Project Manager

A collaborative project management application built with Next.js, TypeScript, PostgreSQL, Prisma, and dnd-kit.

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- shadcn/ui
- Zustand
- TanStack Query
- Prisma
- PostgreSQL
- Auth.js
- dnd-kit
- Vitest
- React Testing Library
- Playwright
